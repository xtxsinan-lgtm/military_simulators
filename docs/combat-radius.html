2. 军推估算THRUST

理想 Brayton 双涵道循环：T4 全包线保持，海平面静止军推反标定换算流量。概念设计级估算，不含进气道/喷管损失。

3. 负载与巡航效率TSFC

空战重量 = 空重 + 一半内油 + 飞行员×0.1 t + 4 枚中距弹。平飞阻力 D=W/(L/D)，负载比 = D/可用军推。再用实际布雷顿循环反解 T4，得到 η_th·η_p 与 TSFC。巡航点使用第 2 栏高度/马赫，升阻比用第 1 栏待估机几何重算。

4. 作战半径RANGE

给定马赫下搜索 L/D×η_o 最大、且阻力 ≤ 军推 92% 的高度，再用布雷盖公式估算作战半径。自动计算 Ma 0.8 / 1.5 / 1.76 以及该机型最大巡航马赫。马赫角优先用预设度数。降落冗余、爬升额外与降落节省一律按亚音速油耗入账（即使巡航点是超音速）。

5. 最大速度Vmax

加力平飞：各高度二分最大马赫（阻力 ≤ 加力 92%），取真速最大点。使用第 2 栏海平面加力标定，空战重量同第 3 栏；不计作战半径。
